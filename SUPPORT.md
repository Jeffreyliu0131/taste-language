# Support

Taste Language is a local prototype with a **Validate first** evidence verdict. It does not provide a hosted service, production uptime, research operations, or real-place recommendations.

Before asking for help:

1. read [README.md](README.md) and [EXPERIENCE_ACCEPTANCE.md](EXPERIENCE_ACCEPTANCE.md);
2. confirm Node.js 22.12 or newer;
3. run `npm ci`, `npm run validate:fixtures`, and the failing command again;
4. remove secrets, personal data, private paths, and rights-unclear media from logs or screenshots.

Use the bug issue form for a reproducible defect and the scoped improvement form for an in-boundary proposal. Include the smallest reproduction and the observed error state. Do not use issues to upload real people, identifiable places, private photos, or images with unclear rights.

Security vulnerabilities must be reported privately through [SECURITY.md](SECURITY.md). General security reports, conduct concerns, and sensitive evidence do not belong in public issues.
